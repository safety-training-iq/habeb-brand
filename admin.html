هذي الصفحة إلك بس. تدخل مرة وحدة من موبايلك ويبقى محفوظ.

شلون أطلع مفتاح الدخول؟ (مرة وحدة بس)
  1. افتح github.com وسجّل دخول بحسابك.
  2. Settings ← Developer settings ← Personal access tokens ← Fine-grained tokens ← Generate new token.
  3. الاسم: habeb-admin — Expiration: اختار المدة اللي تريدها (مثلاً سنة).
  4. Repository access: Only select repositories ← اختار مستودع الموقع.
  5. Permissions ← Repository permissions ← Contents: Read and write.
  6. Generate token وانسخه والصقه هنا. لا تنطيه لأي أحد.
